# Note App Store

Creare un file JSON per la versione reale, ad esempio `2.1.1.json`:

```json
{
  "it-IT": "Descrizione reale delle novità di questa versione."
}
```

Includere tutte le lingue già configurate nella scheda App Store, con note
effettive di 1–4000 caratteri per ciascuna lingua. Fare commit su `main` insieme
alla versione commerciale corretta in tutti i target dell'app.
Il file è un input di produzione: non usare l'esempio come note reali.
